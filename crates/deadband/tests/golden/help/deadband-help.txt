Keep a busy machine usable while many heavy jobs compete for it

Usage: deadband [OPTIONS] <COMMAND>

Run a heavy job when the machine has room
  run         Wait until the daemon admits a job, then run it

See the machine and its jobs
  status      Print the machine's load, memory pressure and swap, and the daemon's jobs
  top         Show the last ten minutes of jobs, load and holds in the terminal

Admit jobs
  daemon      Run the daemon that admits jobs, in the foreground

Explore the commands
  commands    Explore deadband's commands
  schemas     Explore the JSON documents that deadband prints and the files it reads

Install deadband's skill
  skills      Give coding agents deadband's skill

Set up shell completion
  completion  Set up deadband's completion in a shell

Options:
      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --long
          Add the long columns after the compact ones. The default prints only the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

  -h, --help
          Print help (see a summary with '-h')

Topics: exit-codes. `deadband help <TOPIC>` prints one.
