Wait until the daemon admits a job, then run it

Usage: deadband run [OPTIONS] -- <COMMAND>...

Arguments:
  <COMMAND>...  The command to run, after `--`

Options:
      --label <LABEL>  The label that `deadband status` shows for the job. The default is the program's name
      --lane <LANE>    The lane the job waits in. Waiting fast jobs start first and get one more thread, and normal jobs run at nice 5. The default is the fast lane when the priority file matches the job, and the normal lane otherwise [possible values: fast, normal]
  -h, --help           Print help (see more with '--help')

Examples:
  deadband run --label tests -- cargo test

Effects: additive, not idempotent, open-world.
Writes: applies all items or none.
Output: no result on standard output, and --json prints a failure as JSON.
Exit code: the command passes on the exit code of the job.
Global flags: --json, --no-input. `deadband run --help` describes them.
