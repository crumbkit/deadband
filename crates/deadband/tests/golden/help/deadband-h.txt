Keep a busy machine usable while many heavy jobs compete for it

Usage: deadband [OPTIONS] <COMMAND>

Run a heavy job when the machine has room:  run
See the machine and its jobs:               status, top
Admit jobs:                                 daemon
Start the daemon at login:                  service
Explore the commands:                       commands, schemas
Install deadband's skill:                   skills
Set up shell completion:                    completion

Options:
  -h, --help  Print help (see more with '--help')

Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `deadband --help` describes them.
Topics: exit-codes. `deadband help <TOPIC>` prints one.
