Install this tool's skills into each agent skills directory that exists

Usage: deadband skills install [OPTIONS]

Options:
      --dir <DIR>  Install into this skills directory in place of the agent skills directories
      --force      Replace a file or a link that install did not write with the skill's own folder
  -h, --help       Print help (see more with '--help')

Examples:
  deadband skills install
  deadband skills install --force

Effects: additive, idempotent, closed-world.
Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `deadband skills install --help` describes them.
Next: deadband skills install --help explains each column.
