Install the launchd agent that runs the daemon at login and restarts it when it stops

Usage: deadband service install [OPTIONS]

Options:
      --max-jobs <N>
          The most jobs that the daemon runs at once, passed to `deadband daemon`. The default is the daemon's own

      --restart
          Reload a changed agent even while the daemon has running or waiting jobs. The jobs keep running

      --dry-run
          Report what the command would change, and change nothing

      --json
          Print the result as a JSON document. The default prints text.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  deadband service install
          Install the launchd agent that runs the daemon at login

  deadband service install --dry-run
          Print the plist and the launchctl steps

Effects: additive, idempotent, closed-world.
